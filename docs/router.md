# Skill router

Generated by `python3 scripts/catalog.py --write` from owned SKILL.md files. Select the task boundary; do not load the whole catalog. Required resources live inside each skill. Optional neighbors are resolved by name through the host assistant and loaded only when relevant and available.

## Agent runtime

### agentic-loop-engineer

[agentic-loop-engineer](../agentic-loop-engineer/SKILL.md): Engineers reliable agent tool-calling loops with iteration caps, parallel vs sequential execution, tool-class retry classification, tool-error shaping, history growth control, token budgets, and deterministic termination. Use when building an agent runner, agent harness, ReAct loop, tool dispatcher, "tool loop", "max iterations", "parallel tool calls", "why is my agent looping", tool errors, or "when to stop the agent". HTTP 429/5xx and provider retries: llm-client-architect only. Tool-result recovery and tool-class backoff belong here; argument validation, schemas and capability flags belong to tool-registry-architect.

**Use this when:**

- User implements a while-loop that calls LLM then executes tools until done.
- User hits runaway loops, duplicate tool calls, or unbounded message history.
- User needs parallel tool calls vs strict ordering for dependent steps.
- User shapes tool errors for model recovery without leaking stack traces.
- User asks about token limits, summarization, or stopping conditions for agents.

**Hand off (optional):**

- Optional: [llm-client-architect](../llm-client-architect/SKILL.md) — Own provider HTTP retries and protocol translation.
- Optional: [tool-registry-architect](../tool-registry-architect/SKILL.md) — Own schemas, invocation authorization and result classification.
- Optional: [prompt-engineer](../prompt-engineer/SKILL.md) — Own prompt wording and roles.
- Optional: [observability-designer](../observability-designer/SKILL.md) — Define event correlation and export policy.
- Optional: [integration-tester](../integration-tester/SKILL.md) — Verify loop behavior through real wiring.
- Optional: [typescript-cli-architect](../typescript-cli-architect/SKILL.md) — Map terminal outcomes to CLI exits when a CLI exists.

## Performance

### program-performance-optimizer

[program-performance-optimizer](../program-performance-optimizer/SKILL.md): Optimizes programs by measuring first, identifying hot paths, and applying async I/O, caching tiers, and batching with ROI-ranked recommendations—never trading away correctness or security for speed. Use when the user says "slow", "optimize", "performance", "benchmark", "latency", "make it faster", "faster file reads", "cache realpath", or "agent read tools slow". For safe FS caching see secure-filesystem-access scoped realpath cache. Not for removing path guards, skipping realpath checks, or bypassing capability gates for speed.

**Use this when:**

- User reports slow CLI, agent loop, API handler, or batch job.
- User asks to reduce latency, memory, or CPU without a baseline measurement.
- User considers caching, pooling, parallel I/O, or removing await chains.
- User wants ROI-ranked changes before a large refactor.
- User proposes skipping validation or security checks for speed (must refuse).
- User wants faster agent file-read tools without dropping path guards — optionally consult secure-filesystem-access and assess its conditional cache only when directory stability is established; preserve the filesystem security contract.
- User asks to speed up reads without weakening security — measure first (this skill), then assess the conditional cache from secure-filesystem-access; refuse shortcuts that skip validation.

**Hand off (optional):**

- Optional: [secure-filesystem-access](../secure-filesystem-access/SKILL.md) — Assess measured path-cache changes against filesystem threat assumptions.
- Optional: [typescript-security-auditor](../typescript-security-auditor/SKILL.md) — Review changed TypeScript security boundaries.
- Optional: [agentic-loop-engineer](../agentic-loop-engineer/SKILL.md) — Address agent history budgets and dependency ordering.
