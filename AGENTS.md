# Editing owned skills

Read [docs/router.md](docs/router.md) before editing a skill to identify its scope and named neighbors.

A change to a skill’s description or “When to use” section updates the matching router section and boundary row in the same pull request. Check [docs/boundaries.md](docs/boundaries.md) against the explicit handoffs in the skill and its reference file.

When introducing a skill, follow [docs/add-a-skill.md](docs/add-a-skill.md).

Gitignored names are local skill installs and stay untracked. Stage explicit owned paths.
